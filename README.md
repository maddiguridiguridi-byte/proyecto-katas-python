# Proyecto de lógica: Katas de Python

## Descripción

Este repositorio reúne las soluciones de las katas de Python realizadas durante el proyecto. Los ejercicios practican el uso de funciones, listas, diccionarios, `map()`, `filter()`, `reduce()`, expresiones lambda, excepciones, condicionales y programación orientada a objetos.

## Contenido

- `ejercicios.py`: soluciones en Python. Cada ejercicio va precedido de un comentario con su enunciado.
- `proyecto_kata_python_Maddi_Guridi.ipynb` (opcional): cuaderno original de trabajo, si se decide incluirlo en el repositorio.

## Pasos seguidos

1. Resolver las katas en un cuaderno Jupyter (`.ipynb`).
2. Revisar y recopilar los enunciados junto con sus soluciones.
3. Organizar las soluciones en un archivo `.py`, manteniendo el enunciado como comentario antes de cada ejercicio.
4. Preparar este `README.md` para explicar el contenido del proyecto y facilitar su revisión.
5. Publicar los archivos en un repositorio de GitHub y entregar el enlace del repositorio.

## Cómo utilizarlo

1. Descarga o clona el repositorio.
2. Abre `ejercicios.py` en un editor de Python.
3. Ejecuta y prueba los ejercicios individualmente. Algunos ejemplos solicitan datos por teclado (`input()`), por lo que pueden requerir interacción.
